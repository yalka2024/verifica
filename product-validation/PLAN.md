# Product validation plan

**Ideal customer:** Immigrant families and international students seeking immigration help verification

**Problem hypothesis:** Users need to verify immigration help authenticity before sharing sensitive information.

**Activation event:** User submits a verification request

**Retention event:** User returns for multiple verifications

**Paid acquisition:** experiment

Paid acquisition remains an experiment until activation, retention, CAC and LTV evidence supports scaling.

## Experiments
- A/B test UI language toggle
- Test different evidence presentation formats

## Interview questions
- What type of immigration help are you seeking?
- Have you encountered suspicious offers before?
